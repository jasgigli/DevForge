# DevForge Beta Installation

## Quick Start
```bash
# NPM
npm install -g @devforge/cli@beta

# Yarn
yarn global add @devforge/cli@beta

# PNPM
pnpm add -g @devforge/cli@beta
```

## System Requirements
- Node.js ≥ 16
- Rust ≥ 1.65
- Git

## Getting Started
After installation, create your first project:
```bash
devforge new my-app
cd my-app
devforge dev
```
