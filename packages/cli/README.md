# DevForge CLI

Modern development toolkit for streamlined project workflows.

## Installation

```bash
npm install -g @devforge/cli
```

## Usage

Create a new project:

```bash
devforge new my-project
```

Start development:

```bash
devforge dev
```

Build for production:

```bash
devforge build
```
